# Draw bounded discovery areas on the map

Status: accepted for the Demo Mode redesign on 2026-11-12. Implementation pending.

The demo will use a real street map, so Jualokal must state which geographic areas it may draw. The buyer sees one **Maximum Browsing Boundary**: a 10 km circle centered on the current Browsing Location. It uses a thin outline and a low-opacity fill, sits below all markers, does not react to pointer input, and carries a label that states the active 2 km search separately. It shows the permanent maximum area that Jualokal may search, not the current Discovery Radius. Jualokal does not draw the 2 km boundary, because ADR 0019 forbids drawing the precise Discovery Radius boundary. Panning and zooming never change the snapshot, eligibility, or radius; only **Refresh nearby listings** replaces the snapshot, and **Recenter** restores the buyer-centered view.

The seller-side Seller Convenience Zone boundary is deferred from this redesign. Its rule is already settled: a 1 km straight-line area around the seller's protected Home Anchor, inside which the seller chooses a Handover Point. When it is built, only the authorizing seller may see it, only in handover selection; a buyer never sees it, and neither does the seller's buyer-view. The browser must not receive the Home Anchor to draw the circle. The server must send a polygon or a coarse center instead, because Home Anchors never go to ordinary clients. Demo Mode may use fictional display anchors; those are not Home Anchors.

A stable street map cannot place one seller at five listing-level distances. Demo Sellers therefore gain one fictional seller-level distance and one fixed fictional **discovery anchor** for display. Distance Bands and eligibility remain derived from the seller-level distance, and `discoverListings` keeps its current contract. Forced location scenarios keep their eligibility result, but marker geometry can disagree with it; the interface labels those states as simulated evaluations. This replaces the prototype's buyer-relative marker placement and aligns the demo with ADR 0019's rule that a Seller Discovery Marker is stable for every eligible member.

The minimum zoom must allow the full 10 km circle to fit on the smallest supported viewport. The first view stays at the active 2 km area. See `docs/specs/demo-map-first.md` for the interaction and implementation details.
